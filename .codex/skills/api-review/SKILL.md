# API review

Read API architecture/standard and applicable module docs. Trace router dependencies, inputs, service, ORM queries, outputs and exception paths. Record method/path, authentication, permission/ownership, CSRF for cookie mutations, schemas, status codes and data exposure. Test or identify success plus unauthenticated, forbidden, invalid, missing and conflict cases. Flag pagination/versioning only when relevant. Cite file evidence, severity and compatibility impact. A review does not authorize implementation.
