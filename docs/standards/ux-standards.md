# Estándares UX

Requisito de negocio y recomendación UX se etiquetan por separado. Navegación estable por tareas frecuentes; mensajes dicen qué ocurrió y cómo corregirlo; prevenir doble envío y acciones irreversibles; valores y foco se conservan tras error. Responsive desde móvil para marcaje y escritorio para administración. WCAG como referencia: teclado, foco visible, labels, contraste, semántica y no depender solo de color.
