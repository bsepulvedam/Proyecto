# Ciclo de vida del trabajador

Actual: ADMIN crea/edita trabajador y puede vincular una cuenta administrada. No existe onboarding/offboarding formal.

Objetivo propuesto: alta laboral → asignación organizacional/centro → cuenta opcional → cambios efectivos con historial → suspensión/salida → revocación coordinada de acceso. La fecha y efectos del término, conservación documental y reingreso están [PENDIENTE].
