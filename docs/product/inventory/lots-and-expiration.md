# Lotes y vencimientos

[PENDIENTE] No hay lote ni fecha de vencimiento. [PROPUESTO] cada recepción puede crear uno o más lotes con cantidad, costo histórico, vencimiento opcional y ubicación. Las salidas deben asignar lote explícito o por política FEFO; si se reemplaza, registrar reverso y nueva asignación.
