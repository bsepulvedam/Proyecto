# Security review

Read security architecture/standard and risk register. Establish assets, actors, trust boundaries and data sensitivity. Review authentication, session/cookies, CSRF, RBAC/ownership, validation, SQL/XSS, uploads, secrets, logging, errors, GPS/PII and production configuration. Do not expose secrets or perform exploitative/destructive tests. Classify CRITICAL/HIGH/MEDIUM/LOW/IMPROVEMENT with file evidence, realistic impact and scoped remediation. Distinguish technical control from legal/privacy policy and mark undecided policy pending.
