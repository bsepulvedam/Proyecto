# Estándares frontend

La UI activa es Jinja/static. Reusar layout/partials/macros; tokens CSS para color/espacio/tipo. Todo formulario tiene label, error junto al campo, resumen cuando corresponda, valor preservado y confirmación. Mostrar loading, vacío, éxito y fallo. Navegación responde a capacidades, pero backend autoriza. JS es mejora progresiva, no requisito para controles de seguridad.
