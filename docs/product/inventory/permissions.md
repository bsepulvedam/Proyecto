# Permisos de Inventario

[IMPLEMENTADO] ADMIN posee `INVENTARIO_ACCESS`; no existen permisos granulares. [PROPUESTO] separar consulta, catálogo, recepción, despacho, ajuste, costo y auditoría. Costos y ajustes requieren privilegio más restrictivo. [PENDIENTE] alcance por empresa/bodega y segregación de funciones.
