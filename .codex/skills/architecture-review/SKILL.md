# Architecture review

Read architecture, audit, module boundaries and ADR. Start from executable dependencies and deployed assumptions. Evaluate code, feature, data, user, team and operations scale. Preserve the single-app modular-monolith direction unless evidence justifies otherwise. Check ownership: Identity account, RRHH worker, Attendance attendance records, Inventory product/ledger. Separate current state, target, gaps and next steps; classify proposals and open business decisions. Create an ADR only for a significant decision.
